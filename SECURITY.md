# Security policy

Please do not post tokens, real chat messages, personal information or API keys in public issues. To report a security concern, contact contact@harshitethic.com with a minimal reproduction, affected version and recommended mitigation.

If a key was ever published in a commit, **revoke/rotate it**: deleting the file in a later commit does not remove it from Git history.

This repository is a sample bot. Public deployments should add user quotas, abuse controls, monitoring, and key management before exposing it at scale.

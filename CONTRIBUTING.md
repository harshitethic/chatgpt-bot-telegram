# Contributing

Small, reviewable pull requests are welcome.

1. Open an issue describing the bug or improvement and how to reproduce it.
2. Fork the project; make your change on a topic branch.
3. Run `npm ci && npm run check && npm test`.
4. Add tests for behavior changes and explain migrations or breaking changes.
5. Never commit `.env`, API credentials, private chats, generated user content, or third-party data.

A maintainer review is required before a change is considered accepted.
